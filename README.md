# 💸 Dynamic Pricing Engine

An AI-powered Dynamic Pricing Engine built using Machine Learning to predict optimal product prices based on demand, inventory, competitor pricing, and seasonal trends.

## 🚀 Features

* Predicts smart product pricing using AI
* Interactive Gradio UI
* Demand-based pricing
* Inventory-aware recommendations
* Seasonal pricing adjustments
* Competitor price consideration

## 🛠 Tech Stack

* Python
* Pandas
* Scikit-learn
* Random Forest Regressor
* Gradio

## 📂 Project Structure

```plaintext
dynamic-pricing-engine/
│
├── app.py

├── data.csv

├── README.md

```

## ⚙️ Installation

```bash
pip install -r requirements.txt
```

## ▶️ Run the Project

Train model:

```bash
python train.py
```

Run application:

```bash
python app.py
```
